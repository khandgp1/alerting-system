# 00 — Pull BTC Hourly Candle Data (Binance → Markdown)

## Goal

Fetch the last 10 **closed** hourly OHLCV candles for BTC/USDT from the Binance public API and write them into a structured markdown file within this project. No API key required.

---

## Background

Binance exposes a free, unauthenticated REST endpoint for candlestick data:

```
GET https://api.binance.com/api/v3/klines
  ?symbol=BTCUSDT
  &interval=1h
  &limit=11
```

> We request **11** candles and drop the last one, since the most recent candle is still open (not yet closed).

---

## Proposed Changes

### Script

#### [NEW] `scripts/fetch_btc_candles.js`
- Node.js script (no external dependencies — uses native `fetch`)
- Hits the Binance `/api/v3/klines` endpoint
- Drops the in-progress (last) candle, keeping only 10 **closed** candles
- Maps raw response to human-readable fields: `open_time`, `open`, `high`, `low`, `close`, `volume`
- Writes output to `data/btc_hourly_candles.md`

---

### Output

#### [NEW] `data/btc_hourly_candles.md`
- Markdown file generated by the script above
- Contains a table with columns: `#`, `Open Time (UTC)`, `Open`, `High`, `Low`, `Close`, `Volume (BTC)`
- Includes a metadata header: fetch timestamp, symbol, interval, source

---

## Verification Plan

### Automated
- Run `node scripts/fetch_btc_candles.js` and confirm:
  - Exit code `0`
  - `data/btc_hourly_candles.md` is created/updated
  - File contains exactly 10 rows in the table
  - All candle open times are in the past (none are the current hour)

### Manual
- Open `data/btc_hourly_candles.md` and visually confirm prices are reasonable BTC values (e.g., open/close in expected range)
- Cross-reference 1–2 candles against TradingView's BTC/USDT 1H chart
